# Capturas de Quartus

Capturas de pantalla de Quartus II 13.0 SP1 con el proyecto del sintetizador para la EP2C5T144C8 (lista en la TAREA-020 de `COORDINACION.md`). Se toman con `sh tools/tomar_capturas.sh`, que dice que dejar en pantalla para cada una y las guarda aqui con su nombre. Con ellas, `python3 tools/arma_avance.py` arma el PDF del primer avance en `entregas/`.
